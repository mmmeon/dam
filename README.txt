controller for displays and audio that supports:

     * touch bar, menu, and keybinds control the same features.

              * spoken prompts and announcement
         * switch audio output

  * airplay receivers
  * sidecar ipad as primary display
    * auto-connect via sidecar if only display available
  * resolution overrides using virtual displays

  * arrange * extend * mirror * optimize display
      * drag to position in popup
         * relative positioning via menus


      * nickname devices (in the app)
    * hide devices (from the app)

           tested on:
             * intel macbook pros with touchbar
                       * macbookpro14,2 (ventura)
              * ipad
                * ipad6,3 (ios 16)
